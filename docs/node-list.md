# 节点清单（53 个，`NODE_CLASSES` 顺序）

> 节点库除下列 53 个节点外，另有「背景」分组的**背景框**按钮（NodeGraphQt
> `BackdropNode`，`kind="backdrop"`）——它不是 StudioNode，不进 `NODE_CLASSES`，
> 无端口/参数/执行，仅作画布分组框。
